# 罗小黑桌宠

## 修改

几个状态
  - 坐姿待机：`cat-sit.webp`
  - 趴趴：`cat-loaf.webp`
  - 喂食/吃东西：`cat-talk.webp`
  - 摸摸头：`cat-happy.webp`
  - 警觉：`cat-alert.webp`
  - 逗猫：`cat-play.webp`
- 看剧情素材：`cat-read.webp`。
- 点击“罗小黑评剧情”时，罗小黑会切换成看书/看剧情动作。
- `cat-sit-eyebase.webp` 仍只用于长按眼珠跟随交互。

## 保留

- 画质模式按钮
- 双 API 大脑
- 剧情预览框
- 角色卡/世界书读取状态
- 动作切换不闪破图
- 状态小框可拖动
