# 罗小黑桌宠 v0.8.0 画质模式菜单版

本版基于 v7.9，新增扩展程序菜单里的“罗小黑画质”按钮组。

## 新增

- 罗小黑画质
  - 高清模式
  - 平衡模式
  - 省电模式

## 当前逻辑

- 默认高清模式。
- 高清模式会使用当前高清动态素材，并提前预加载常用动作素材，减少第一次切换时的等待。
- 平衡模式 / 省电模式先作为设置入口保留，后续可以继续接入对应的转码素材或播放策略。
- 不改变 v7.9 已经修好的素材、右侧竖线、动作切换破图、API 大脑、互动菜单剧情点评等功能。

## 保留

- v7.9 素材修复
- v7.6 动作切换不闪破图逻辑
- 双 API 大脑
- 罗小黑本体互动菜单里的“罗小黑评剧情”
- 剧情预览框
- 角色卡/世界书只显示读取状态，不展示原文
- 状态小框可拖动
- 长按注视互动
