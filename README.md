# 罗小黑桌宠 v0.8.1 真高清动态优化版

本版根据反馈修正 v8.0 的“高清模式”。

## 重点修复

v8.0 的高清模式只是加了按钮和全量预加载，这反而会让启动和切换更重。  
v8.1 改成真正适合高清动态素材的播放方式：

- 高清模式不再一次性预加载全部 animated WebP。
- 不再预加载长按注视用的大素材。
- 只在切换动作前，对“即将切换的那个动作”做单素材预加载。
- 高清模式不再叠加 CSS 呼吸、弹跳、旋转等假动作。
- 动态效果完全交给你生成的高清动态素材本身。
- 保留 v7.6 动作切换不闪破图逻辑。
- 保留 v7.9 素材修复和右侧竖线修复。

## 画质模式

- 高清模式：原始高清动态素材 + 单素材预加载 + 关闭额外 CSS 假动作。
- 平衡模式：入口保留，后续可以接入平衡转码素材。
- 省电模式：入口保留，后续可以接入省电播放策略。

## 保留

- 双 API 大脑
- 罗小黑互动菜单剧情点评
- 剧情预览框
- 角色卡/世界书读取状态
- 状态小框可拖动
- 长按注视互动
