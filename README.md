# 罗小黑桌宠 v0.7.1

本版在 v7.0 双 API 大脑测试版基础上调整：

## 修改

- 汤姆猫长按互动的眼珠大小恢复到 v6.33 那版的尺寸。
- “预览剧情”不再只显示在罗小黑气泡里，而是显示在扩展程序菜单里的预览框。
- 调试模式下，实际发送给 API 的剧情也会显示在扩展菜单预览框。
- 罗小黑本体互动菜单里新增按钮：`💬 罗小黑评剧情`。
- 点击该按钮会关闭互动菜单，然后调用当前设置的 API 来源来评论剧情。

## API 来源仍然支持

- 使用酒馆当前 API
- 使用独立 API
- 优先独立 API，失败用酒馆 API
- 优先酒馆 API，失败用独立 API

当前仍然是手动触发版本，不自动监听剧情。
