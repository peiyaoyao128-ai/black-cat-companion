# 罗小黑桌宠 v0.8.3 新动态素材 + 看书剧情动作版

本版基于 v8.1。

## 修改

- 待机动作改回普通 `cat-sit.webp`，不再使用 `cat-sit-eyebase.webp` 当待机。
- 替换你新上传的动态素材：
  - 坐姿待机：`cat-sit.webp`
  - 趴趴：`cat-loaf.webp`
  - 喂食/吃东西：`cat-talk.webp`
  - 摸摸头：`cat-happy.webp`
  - 警觉：`cat-alert.webp`
  - 逗猫：`cat-play.webp`
- 新增看剧情素材：`cat-read.webp`。
- 点击“罗小黑评剧情”时，罗小黑会切换成看书/看剧情动作。
- `cat-sit-eyebase.webp` 仍只用于长按眼珠跟随交互。

## 保留

- v8.1 真高清动态播放逻辑
- 画质模式按钮
- 双 API 大脑
- 剧情预览框
- 角色卡/世界书读取状态
- 动作切换不闪破图
- 状态小框可拖动
